# 공시한눈 한국 베타 구현 체크리스트

이 문서는 기능 단위의 구현 상태를 계속 갱신한다. 전체 화면·반응형·운영 점검은 기능 구현이 끝난 뒤 마지막 단계에서 수행한다.

## 상태 기준

- `[ ]` 시작 전
- `[~]` 구현 중
- `[x]` 구현 및 관련 자동 테스트 완료
- 최종 통합 점검 전에는 개별 항목이 `[x]`여도 출시 완료로 간주하지 않는다.

## 운영 메모

- 사이트 자동 배포는 비활성화 상태를 유지하고, 검증된 릴리스만 수동 배포한다.
- 실데이터 수집 작업은 사이트 공개 여부와 독립적으로 GitHub Actions에서 실행한다.
- 일별 종가는 평일 16:10·18:20 KST 수집을 목표로 하며 실시간 시세로 표기하지 않는다.
- 공시는 평일 08:00~20:59 KST에 10분 간격 수집을 목표로 한다.
- 자동 수집은 `staging` 최종 점검 뒤 운영 브랜치에 반영한다.
- 현재 남은 순서는 배포 환경에서 관심기업·브라우저 알림 실제 수신 확인 → 360/768/1280 통합 QA → 이메일 알림 후속 구현이다.
