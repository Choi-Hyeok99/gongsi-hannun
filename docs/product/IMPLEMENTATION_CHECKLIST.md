# 공시한눈 한국 베타 구현 체크리스트

이 문서는 기능 단위의 구현 상태를 계속 갱신한다. 전체 화면·반응형·운영 점검은 기능 구현이 끝난 뒤 마지막 단계에서 수행한다.

## 상태 기준

- `[ ]` 시작 전
- `[~]` 구현 중
- `[x]` 구현 및 관련 자동 테스트 완료
- 최종 통합 점검 전에는 개별 항목이 `[x]`여도 출시 완료로 간주하지 않는다.

## 우선순위

- [x] 1. 심층 리포트 실제 데이터 연결
  - [x] Supabase `ai_analyses` 성공 결과만 사용자 화면에 표시
  - [x] 요약, 중요성, 중요도, 확인 항목, 주의사항, 생성 시각을 저장값으로 표시
  - [x] 원문 대조가 끝난 숫자만 문서 위치와 연결
  - [x] 미생성·대기·분석 중·실패 상태와 마지막 상태 변경 시각 구분
  - [x] 상태 조회와 리포트 렌더링 자동 테스트 완료
- [ ] 2. 전체 화면 하드코딩·미완성 표현 제거
  - [ ] 기업 수, 공시 수, 최근 수집 시각을 조회값으로 통일
  - [ ] 기업·공시·주가의 빈 상태를 실제 원인별로 구분
- [ ] 3. 모바일 핵심 화면 확인 및 보완
  - [ ] 상단 탐색, 공시 달력, 차트, 상세 화면을 360px 기준으로 확인
- [ ] 4. 관심기업·알림 실제 흐름 확인 및 보완
  - [ ] 저장, 중복 제출, 새 공시 알림, 읽음 처리 확인
- [ ] 5. 최종 통합 점검
  - [ ] 360px, 768px, 1280px 반응형 점검
  - [ ] 로딩·빈 상태·오류 상태 점검
  - [ ] 데이터 수집·AI 분석·배포 전 출시 체크
  - [ ] 실제 수집 데이터로 분석 생성 작업 실행 및 표본 확인

## 운영 메모

- 사이트 자동 배포는 현재 비활성화 상태를 유지한다.
- 일별 종가는 평일 16:10·18:20 KST 수집을 목표로 하며 실시간 시세로 표기하지 않는다.
- 공시는 평일 08:00~20:59 KST에 10분 간격 수집을 목표로 한다.
- 자동 수집은 `staging` 최종 점검 뒤 운영 브랜치에 반영한다.
